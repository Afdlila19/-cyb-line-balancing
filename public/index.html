How moves are checked

  • Blocked the datum knock pin holes in CYB-10M; anything that would run before work it depends on (rough before finish, drill before tap or counterbore, spot face before the hole in it, the same callout in an earlier station).
  • Major into a special-purpose machine (SPM) or CYB-10M (located on the raw casting); a face the target machine does not reach today and cannot index to.
  • Check a face the target does not cut today but may reach by indexing; a new tool type for the target's magazine; tight tolerances that need capability re-proven; taking work off an SPM head.
  • OK same face, tool type already in the target, order respected. Still confirm with the process engineer before changing a program.
